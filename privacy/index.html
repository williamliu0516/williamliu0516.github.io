Privacy Policy — Hermes Mail Reader

Last updated: 2026-09-23

Hermes Mail Reader is a personal, single-user application operated by William (Xiawei) Liu. It exists only to let a self-hosted assistant running on the operator's own computer read the operator's own mailboxes. It is not offered to the public and has no users other than its operator.

What data is accessed

The application requests the Google OAuth scope https://www.googleapis.com/auth/gmail.readonly. With it, the application reads message metadata (sender, subject, date, snippet) and, when explicitly requested by the operator, message bodies. It does not request permission to send, modify, label, or delete mail.

How data is used

Mail is read solely to produce private summaries and reminders for the operator. Some summaries are generated with the help of a third-party language-model API selected by the operator; message content sent for that purpose is used only to generate the response and is governed by that provider's terms.

Storage and sharing

OAuth tokens are stored only on the operator's own computer with restrictive file permissions. Mail content is not persisted beyond what is needed to generate a summary, and nothing is sold, shared with advertisers, or disclosed to any other person.

Limited Use disclosure

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions, which immediately invalidates the stored tokens.
